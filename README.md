## Requirements
To locally run this project, it's necessary to fill the following requirements:
<ul>
  <li>Node 18.x or superior</li>
  <li>pnpm 10.x or superior</li>
</ul>

## How to run
To locally run the project, follow these steps:
<h3>
  <img src="https://skillicons.dev/icons?i=github" style="vertical-align: middle;" />
  Clone:
</h3>
<ul>
  <li>
    Clone the project to your computer using the command: 
    <dt>
    
    git clone https://github.com/paulo-campos-57/Projeto-TCC-FrontEnd.git
  </dt>
  </li>
</ul>

##

<h3>
  <img src="https://skillicons.dev/icons?i=react" style="vertical-align: middle;" />
  Frontend:
</h3>
<ul>
  <li>First, go to the Projeto-TCC/tcc-frontend folder.</li>
  <li>
      After that, install the project dependencies, using the command: 
      <dt>
      
      pnpm install
  </dt>
  </li>
  <li>
      Once the dependencies are installed, run the frontend server using the command: 
      <dt>
      
      pnpm dev
  </dt>
  </li>
  <li>After that, the Front-End server will be running locally on port 5173.</li>
</ul>
